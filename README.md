# Mentoreando contenido

Imágenes de los posts de @mentoreando para programarlos en Metricool con URLs raw públicas.

Una carpeta por post: `AAAA-MM-DD_tema/` con `01.png`, `02.png`… y `texto.txt` (pie de foto).
URL de cada imagen: `https://raw.githubusercontent.com/osmarcolina/mentoreando-contenido/main/<carpeta>/<archivo>`
